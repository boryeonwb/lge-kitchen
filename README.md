# 광고주 공유용 운영·정산 대시보드 (lge-adv-dashboard)

LG전자 냉장고(HS NPI) 광고주에게 공유하는 화면입니다. 탭은 둘입니다.

| 탭 | 내용 |
|---|---|
| **정산** | 인보이스에서 읽은 금액(통화·인보이스 최종금액·DST안분·무효반영·광고비net)과, 그 라인이 세금계산서로 나가는 금액(적용환율·매체비KRW·와이즈버즈 수수료KRW·최종 발행 금액·발행월·처리주체). **키친만** 다룹니다 |
| **운영** | 품의예산(USD/KRW)·품의환율 대비 잔여금과, 남은 기간에 태울 세팅 예산(총예산·일예산·세팅통화), 그리고 월별 소진(세팅통화·KRW) |

**이 저장소에는 프런트엔드만 있습니다.** 계산도 데이터도 없습니다.

---

## 숫자는 어디서 오는가

```
lge-billing-dashboard (내부 정산 대시보드)
  backend/calc.py · ops.py        ← 인보이스 파싱 결과 · 환율 · 품의예산 시트
  backend/adv.py                  ← 광고주에게 보여줄 열만 고르는 화이트리스트
      GET /api/adv/settlement
      GET /api/adv/ops
            │
            │  (nginx 프록시 /api → 그 백엔드)
            ▼
lge-adv-dashboard (이 앱)          ← 표시만 한다. 읽기 전용
```

**데이터를 복제하지 않는 이유가 있습니다.** 적용환율(HSAD 내부환율), 매체비·수수료 수기수정,
세금계산서 발행월, 품의환율, 월별 원통화 소진액은 **사람이 내부 대시보드 UI 에서 입력한 값**이고
그쪽 PVC 에만 존재합니다. 여기서 따로 들고 있으면 광고주 화면이 내부 화면과 조용히 어긋납니다.
그래서 백엔드를 공유합니다 — 내부에서 값을 고치면 이 화면도 같이 바뀝니다.

**보이지 않는 것:** 청구율, 내부 최종금액 KRW, 차액(세금계산서−내부), 수익/손실, 계정ID,
비고·메모·수정 이력, 인보이스 원본 PDF, 내부 운영 경고, 미디어믹스 시트 링크.
거르는 위치는 이 앱이 아니라 **백엔드**입니다(`backend/adv.py`) — 브라우저까지 오지 않습니다.

> **인증이 없습니다.** 주소를 아는 사람은 볼 수 있습니다(요청 사항). 내부 대시보드의 운영 화면은
> 비밀번호로 막혀 있지만 `/api/adv/ops` 는 그 일부를 열어 줍니다. 막아야 하면 백엔드의
> `_ops_guard` 와 같은 방식으로 별도 비밀번호를 붙이면 됩니다 — 쓰기 경로는 원래 없습니다.

## 실행

```bash
npm install
npm run dev            # → http://127.0.0.1:3100
```

`/api` 는 `http://127.0.0.1:8000`(정산 백엔드)으로 프록시됩니다. 다른 포트로 띄웠으면:

```bash
API_TARGET=http://127.0.0.1:8123 npm run dev
```

백엔드 쪽은 `lge-billing-dashboard/backend` 에서 띄웁니다(경로 설정은 그쪽 README 참고):

```bash
uvicorn main:app --port 8000
```

`npm run typecheck` · `npm run build` 로 검사·빌드합니다.

## 배포

`argocd-app-chart` 가 `image.repository` / `nameOverride` / ingress
(`lge-adv-dashboard.wisebirds.ai`)를 자동 주입합니다. `deploy/values.yaml` 은 **frontend
컴포넌트만** 정의합니다 — backend 도 PVC 도 없습니다.

| 환경변수 | 기본값 | 내용 |
|---|---|---|
| `API_UPSTREAM` | `http://lge-billing-dashboard-backend:8000` | `/api` 를 넘길 정산 백엔드 주소. 컨테이너 기동 시 `envsubst` 로 `templates/default.conf.template` 에 채워집니다 |

서비스 이름이 다르면 `deploy/values.yaml` 의 `API_UPSTREAM` 만 고칩니다. 다른 네임스페이스면
`<svc>.<namespace>.svc.cluster.local:8000`, 클러스터 밖이면
`https://lge-billing-dashboard.wisebirds.ai` 도 됩니다. nginx 는 변수 없는 `proxy_pass` 의
호스트를 **기동 시 한 번** 해석하므로, 주소가 틀리면 조용히 500 을 내는 대신 기동에 실패합니다.

## 디자인 — Popcorn (warm editorial monochrome)

크림색 종이(`#f7f7f7`) 위의 따뜻한 그래파이트(`#393737`). 색을 거의 쓰지 않고 서체 대비·자간·
부드러운 그림자 하나(`rgba(0,0,0,.05) 0 4px 20px`)로 위계를 만든다. 인터랙티브한 표면은
전부 pill(100px), 판은 12px 라운드.

토큰은 `src/styles.css` 의 `@theme` 한 군데에 모여 있다. 서체는 `index.html` 이 구글 폰트로
불러온다 — 막힌 망에서는 스택의 시스템 서체로 조용히 내려간다.

| 가이드 | 여기서 쓴 것 | 이유 |
|---|---|---|
| Untitled Serif (디스플레이) | **Source Serif 4** + 한글 **Noto Serif KR** | 유료 커스텀 서체라 가이드가 지정한 대체서체. 제목이 대부분 한글이라 한글 세리프를 짝지어 둔다 — 없으면 한글만 시스템 명조로 떨어져 한 줄의 인상이 갈린다 |
| Messina Sans (기능) | **Inter** + 시스템 고딕 | 같은 이유 |

**가이드에서 일부러 다르게 해석한 세 가지** — 원본은 마케팅 랜딩이고 이건 열이 서른
개가 넘는 표라, 그대로 옮기면 쓸 수 없는 화면이 된다.

1. **디스플레이 세리프는 제목·KPI 숫자에만.** 페이지 제목 22px, 섹션 제목 22px,
   KPI 숫자 40px. 표 안 글자는 사스 기능 사이즈(11·13·14px)로 내렸다 — 본문 16px 을
   표에 쓰면 한 화면에 여덟 줄밖에 못 담아 대조가 안 된다. 가이드의 84px 는 쓰지 않는다.
2. **수익/손실·초과 같은 신호를 채도 있는 글자색 대신 연한 틴트 pill 로** 냈다.
   시스템이 채도 있는 텍스트를 금지하는데, 금액 화면에서 음수·초과를 구분 없이 두면
   눈에 안 들어온다. 스펙트럼 워시의 blush(`#f7dbe5`)·amber(`#fef1d8`)·mist(`#e9eff6`)를
   배경으로만 쓴다. 숫자 열에서는 배지 오른쪽 여백만큼 당겨 자릿수가 안 어긋나게 한다.
3. **페이지 폭을 1200px 로 안 묶었다**(1720px). 운영 탭은 고정 13열 + 월별 2열이라
   1200px 에 넣으면 고정열만 보이고 가로 스크롤로만 읽게 된다.

## 화면에서 알아둘 것

**정산 탭**

- `광고비net` = 집행 + DST안분 + 무효반영. **인보이스 통화 그대로**라 소계·합계는 통화별로 나눠 냅니다.
- `인보이스 최종금액`은 그 라인이 속한 **인보이스(계정)의 발행 총액**이라 집계행마다 되풀이됩니다 →
  합계를 내지 않습니다(내면 중복 계상).
- `최종 세금계산서 발행 금액` = 매체비KRW + 수수료KRW. 단 **처리주체가 HSAD(광고주계정)** 인 행은
  매체비를 광고주가 매체에 직접 지불하므로 **수수료만** 발행합니다 → 그 행의 매체비 칸은 흐리게 내려둡니다.
- `적용환율`은 세금계산서 환산 환율입니다. Criteo 는 HSAD 내부환율, 그 외 매체는 정산 적용환율과 같습니다.

**운영 탭**

- 월별 소진 KRW 는 한 달에 **하나만** 쓰고, 어느 값을 쓸지는 서버가 정합니다:
  **확정**(인보이스, 굵게) > **수기**(매체 리포트 기준, 틴트 배지) > *계획*(잔여액을 남은 일수에 일할
  배분 · 기울임, **실적이 아님**). 세팅통화 칸도 **같은 출처**로 짝을 맞춰 두 칸이 어긋나지 않습니다.
- `잔여액` = 품의예산(KRW) − 확정 − 수기 = **아직 어느 달에도 배분되지 않은 돈**입니다.
  '앞으로 쓸 수 있는 돈'이 아니라 계획이 덜 짜인 금액이라, 0 에 가까울수록 품의에 맞게 계획된 상태입니다.
  종료됐는데 남아 있으면 그만큼 못 쓰고 끝난 것이라 ⚠ 로 표시합니다.
- `세팅 일예산`은 **오늘 매체에 넣을 값**, `세팅 총예산`은 **캠페인 총예산 칸에 넣을 값**(이미 태운
  몫 포함)입니다. 원통화 열은 행마다 통화가 달라 합계를 내지 않습니다.
- 기간·잔여일은 **각 국가 현지 날짜** 기준입니다.
- 월 열은 값이 하나라도 있는 달만 냅니다. **전체 행 기준**으로 정하므로 드롭다운을 바꿔도 월 위치는
  고정됩니다.
